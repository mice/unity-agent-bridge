# AGB_214

## Requirement

Rejecting one plugin tool because its declared MCP name conflicts must not reserve that tool's bridge command or prevent a later valid declaration from registering.

## Assertions

- The first plugin tool owns the shared MCP name.
- The conflicting declaration is rejected with a plugin-scoped diagnostic.
- A later tool using the same bridge command with a distinct MCP name is registered and cataloged exactly once.

## Latest Run Result

Passed in Unity 2022.3.53f1 as part of the focused discovery-driven rc.6 EditMode run (`16/16`).
