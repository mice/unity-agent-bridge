# AGB_198

## Requirement

An invalid persistent-hierarchy locator must return a structured hierarchy failure without Newtonsoft `JArray` to `JToken` serialization errors.

## Assertions

- A trailing-slash `dontDestroyOnLoad#.../` locator returns `invalid_args`.
- The result and persisted report contain `AGENTBRIDGE_LOCATOR_UNSUPPORTED`.
- The persisted report parses as JSON.
