# AGB_213

## Requirement

An external plugin that implements `IUnityMcpToolProtocolMetadata` must be able to declare a canonical MCP name that cannot be derived by Agent Bridge's compatibility mapper.

## Assertions

- The compatibility mapper has no entry for the fixture bridge command.
- Unity registers the original bridge command.
- Catalog V1 exports the plugin-declared MCP name unchanged.
