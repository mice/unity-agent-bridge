## Requirement
Bridge health must classify stale heartbeat state as a non-ready degraded condition and provide reconnect guidance.

## Expected Result
Stale bridge sessions have an explicit non-ready degraded lifecycle classification without promoting `stale` to a top-level lifecycle state.
