## Intent

Expired processing commands must be converted into terminal timeout results during recovery.

## Preconditions

- Temporary queue root is writable.
- Recovery clock is fixed so the seeded command is expired.

## Procedure

1. Enqueue and dequeue a command into `processing/`.
2. Rewrite its state with an old `startedAt`.
3. Call `Recover()`.

## Expected

- Recovery records a `TimedOut` action for the command.
- `outbox/{id}.result.json` exists with `status = timeout`.
- The processing command is moved into `failed/`.
