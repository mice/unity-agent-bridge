# AGB_371

## Requirement
SCHED-G02/G03; preserve existing compile diagnostics during synchronous startup/import.

## Risk
A startup that blocks the Editor main thread past its budget can replace a deferred operation result with a generic timeout before its typed lifecycle owns completion.

## Steps and Assertions
For Pending, Running and Resuming variants, advance an injected clock past the startup budget and assert the same original result remains deferred with truncation diagnostics. Existing AGB_041 still requires late synchronous success to become timeout. The public scheduler separately expires the original deadline and tracks physical ownership; this isolated facade test does not claim public execution success.
